## Description:

A full-stack MERN (MongoDB, Express.js, React, Node.js) application where users can browse and read free books. Authenticated users have access to all books, while guests can only view limited content. The backend is secured with bcryptjs for password hashing, and dotenv for environment management. Data is stored in MongoDB and managed using Mongoose. The server uses Express.js with CORS enabled, and the development process is streamlined using nodemon.

## Technology Used:
- JavaScript, MongoDB, ExpressJs, ReactJs, NodeJs, Tailwind, Vite,
- Mongoose, bcryptjs, dotenv, CORS, Nodemon, Heroku Deployment.
